Event reporting

It is important to report the various events we host and attend, because that shows our value when interacting with customers. You should record events if your attendance somehow is there to assist the event or somehow promote ASC, HPC, or RSE. The reporting is by mainly for events, not a tracking for who attended what.

You should record these in the following places:

  • Group meetings: These are meetings with one or a few research groups [vs department meetings: If it’s an event across a] to {answer their questions, introduce ourselves to them}. Document them in the Data Agents google drive - there are spreadsheets for each department. Search RG visits and ask in chat for the link or to be added.

  • Courses we have hosted: In the course spreadsheet in Google Drive (link TODO).
