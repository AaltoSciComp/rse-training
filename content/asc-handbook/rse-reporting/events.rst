Event reporting
===============

It is important to report the various events we host and attend,
because that shows our value when interacting with customers and it
goes into various reports.  You should record events if your
attendance somehow is there to assist the event or somehow promote
ASC, HPC, or RSE.

You should record these in the following places, depending on what it
is:

* If **Courses we have hosted:** In the course spreadsheet in Google
  Drive (search: ``Course stats``).

* elif **Group meetings:** These are meetings with one or a few research
  groups :inote:`[vs department meetings] If it's an event across a
  department, see below instead.` to {answer their questions,
  introduce ourselves to them}.  Document them in the Data Agents
  google drive - there are spreadsheets for each department.  Search
  ``RG visits`` and ask in chat for the link or to be added.  If you
  don't have access, ask in chat or record below.

* else **Anything not above**, including if you don't know where it
  goes: Google Drive search ``Events and outreach activities`` and add
  a row there.  (Those making reports patrol this document and will
  move or copy it to the right place if needed).

It can be hard to know where something should be recorded.  If you are
unsure, you can use the last spreadsheet and someone else will fix it
up later.

There are other places to report things, for example LAIF reporting
spreadsheets.  If you use one of the above, it will eventually get
transferred there by someone responsible for those reports.
