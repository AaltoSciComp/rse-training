# Aalto SciComp RSE training material

This contains material for RSE onboarding and training.  It's not
designed to be a course, but instead is some combination of checklist
and wiki notes.

Status: still very much a draft, but documents what we actually do.

Editor: rkdarst


## Internal Aalto pages

This site can be build with a private submodule, which then includes
more pages.  To update the submodule (if you have access):

```console
$ git submodule init
$ git submodule update
```

And after that there is a README within this with more info.
